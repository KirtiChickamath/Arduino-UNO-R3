# Arduino-UNO-R3
This project is a complete 4-layer PCB redesign of the Arduino UNO R3

## Project Details

**Project Name:** Arduino UNO R3

**Software Used:** Altium

This project is inspired by the (https://www.youtube.com/watch?v=JppDLGh5hUs&list=PLhzgb9TEt7AXkJYzJQ6IhN_OXhj9bZ_wQ)

## Features


- 4-layer stackup
- ATmega328P microcontroller
- ATmega16U2 USB-to-UART interface
- USB connectivity with ESD protection
- 16MHz crystal oscillators
- On board 5v and 3.3v regulation - NCP1117 and LP2985 regulators
